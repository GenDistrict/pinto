**AI 이미지 지시 편집기 최종 기획안**

확정일: 2026-10-15. Windows와 macOS에서 사용하는 데스크톱 앱의 구현 기준이다. 사용자 편의성을 최우선으로 하며, thread0의 로컬 AI가 저장소에서 소스를 내려받아 설치하고 사용자 요청에 따라 수정할 수 있게 만든다.

표시 도구 개정: **네모·동그라미·점·선·자유도형**을 각각 선택할 수 있게 한다. 점은 클릭하고 나머지는 드래그해 표시한다. 자유도형은 손으로 그리는 방식이다. 동그라미의 크기와 선의 양 끝점을 조절할 수 있으며, 다른 종류의 도형도 같은 지시에 연결한다.

2026-10-15 사용성 개정: 새 작업의 전체 지시 입력란과 기본 화면의 작업 폴더 연결을 제거한다. 점·사각형에 자유선을 추가한다. 화면과 복사 완료 안내에서 **원본을 만든 AI 대화의 다음 메시지에 붙여넣기, 새 대화에는 원본 이미지도 함께 전달하기**를 명시한다. 폴더 설정은 보조 메뉴의 이미지 보관 위치 변경으로 제공하고, 이전 버전의 전체 지시 데이터는 보존한다. 아래 초기 설계와 충돌하는 경우 이 개정 내용을 우선한다.

**핵심 경험은 이미지 열기 → 가리키고 입력하기 → 지시 복사다.**

사용자는 이미지의 특정 위치나 영역을 가리키며 수정 지시를 작성한다. 앱은 참고 이미지의 로컬 경로와 정확한 좌표를 지시문에 붙인다. 사용자가 이를 AI 대화에 붙여넣으면 AI가 해당 파일을 열어 지시를 해석한다. 이미지 편집과 스크린샷을 참고한 코드·UI 수정에 모두 사용할 수 있다.

전제는 AI가 참고 이미지 파일을 읽을 수 있는 로컬 환경이라는 점이다. AI가 앱을 열 때 현재 작업 폴더를 함께 전달해 이 경로를 맞춘다. AI 모델 호출과 대화는 thread0에서 수행하며, 앱은 지시 작성과 전달에 집중한다.

| 항목 | 확정 내용 |
| --- | --- |
| 창 | 이미지 미리보기처럼 바로 열리는 독립 데스크톱 창 |
| 지원 환경 | Windows와 macOS. Windows x64·ARM64, Mac Apple Silicon·Intel을 검증 대상으로 설정 |
| 기술 | Electron + React + TypeScript, 이미지 위 SVG 주석 표시 |
| 배포 | 저장소의 소스 코드 다운로드와 로컬 실행 |
| 설치 담당 | thread0에서 사용자의 설치 요청을 받은 Claude Code 또는 Codex |
| 사용자 변경 | 설치된 로컬 소스를 AI가 요청에 맞춰 수정하고 재실행 |
| 기본 전달물 | 이미지 경로 + 이미지 크기 + 좌표 규칙 + 지시문 |
| 데이터 보관 | 로컬 이미지 파일과 버전 정보가 있는 JSON |

**설치는 앱 창이 열리고 AI 세션에 사용·수정 안내가 전달되어야 완료된다.**

사용자가 thread0에 저장소 URL과 “이 앱 깔아줘”라고 입력하면, 설치를 수행하는 AI가 README의 설치 안내를 읽고 다음 절차를 진행한다.

1. 운영체제, CPU, 사용 가능한 실행 환경과 기존 설치를 확인한다.
2. 안정 버전의 소스를 로컬 폴더에 내려받는다. Git이 없어도 소스 압축본으로 설치할 수 있게 한다.
3. 호환되는 Node.js가 있으면 활용하고, 필요하면 앱 전용 위치에 실행 환경을 준비한다. 기존 프로젝트의 실행 환경은 보존한다.
4. 잠금 파일에 지정된 패키지를 설치하고 화면 코드를 빌드한다. 네이티브 컴파일이 필요한 추가 패키지를 도입하지 않는 것을 기본으로 한다.
5. 실행 바로가기와 AI가 호출할 실행 명령을 준비한다.
6. 독립된 앱 창을 열고 화면 초기화까지 확인한다. 설치 중단·실행 실패는 성공으로 보고하지 않는다.
7. 설치 결과를 AI에게 반환하고, AI가 같은 대화에서 실행 방법과 소스를 수정할 수 있다는 사실을 알려준다.

일반 실행은 빌드된 로컬 화면을 연다. 개발 서버나 터미널을 사용자가 관리할 필요가 없도록 한다. 코드가 바뀌면 AI가 필요한 빌드를 수행한 뒤 앱을 재실행한다.

Electron의 공식 실행 환경을 그대로 두고 로컬 프로젝트 코드를 로드하는 방식을 사용한다. 우리 앱을 배포하기 위한 유료 개발자 인증서나 공증을 필수로 두지 않는다. 운영체제와 thread0의 실행 권한 확인은 해당 환경의 정책을 따른다. Electron은 프로젝트 디렉터리의 코드를 실행하는 방식을 공식적으로 지원한다. [Electron 프로젝트 실행 문서](https://www.electronjs.org/docs/latest/tutorial/tutorial-first-app)

설치 스크립트는 다시 실행해도 기존 소스와 데이터를 보존하고, 설치 상태를 확인하거나 필요한 부분을 복구할 수 있어야 한다. 재다운로드가 필요한 경우 이미 받은 실행 환경과 패키지 캐시를 활용한다. 지원하는 최소 OS 버전과 실행 환경 버전은 구현 때 고정해 저장소에 명시한다.

**설치 후 AI의 응답에는 로컬 소스를 수정할 수 있다는 안내를 반드시 포함한다.**

설치 스크립트는 사람이 읽을 수 있는 안내와 구조화된 결과를 반환한다. 결과에는 설치 상태, 버전, 소스 경로, 실행 명령, 데이터 위치, 수정 안내 문서 경로, 화면 실행 확인 결과를 담는다. 설치를 수행한 AI가 이를 읽고 현재 대화에 완료 안내를 작성한다.

설치 후 대화 예시는 다음과 같다.

```text
설치했고 앱 창을 열었습니다.

이 앱은 이 PC에 내려받은 소스를 수정해서 사용할 수 있습니다.
원하는 동작을 말해 주시면 제가 코드를 수정하고 확인한 뒤 다시 실행할 수 있습니다.

예: “코멘트 글자를 더 크게 해줘.”
    “복사되는 지시문 형식을 바꿔줘.”
    “내가 쓰는 단축키로 바꿔줘.”

소스 위치: <설치된 소스 경로>
실행 방법: <이 환경에서 확인된 실행 명령 또는 바로가기>
수정 안내: <설치된 소스 경로>/AGENTS.md
```

이는 설치 도구의 반환값을 읽은 AI가 응답하는 흐름으로 구현한다. 임의로 다른 대화에 메시지를 주입하는 thread0 기능을 가정하지 않는다. README와 설치 안내에는 이 완료 응답을 설치의 마지막 단계로 명시한다.

새 AI 세션에서도 수정할 수 있도록 앱의 보조 메뉴에 **앱 수정 안내 복사**를 제공한다. 이 기능은 소스 경로, 안내 문서 경로, 실행·확인 명령을 복사한다. 사용자는 이를 새 대화에 붙여넣고 원하는 변경을 요청할 수 있다. 이미지 수정용 **지시 복사**와 앱 자체를 고치는 **앱 수정 안내 복사**는 이름과 위치를 명확히 구분한다.

**편집 화면은 이미지와 하나의 주요 버튼을 중심으로 구성한다.**

이미지가 화면 대부분을 차지한다. 상단에는 파일 이름, 파일 열기와 실행 취소 등 작은 보조 조작, 가장 눈에 띄는 **지시 복사** 버튼을 둔다. 하단에는 선택 사항인 전체 지시 입력란을 둔다. 코멘트는 작성·수정할 때 펼쳐지고, 평소에는 작은 번호로 접힌다. 모든 코멘트를 확인하는 목록은 필요할 때 펼친다.

중립적인 배경과 하나의 강조색을 사용한다. 영역은 얇은 테두리와 옅은 채움으로 표시해 이미지 내용을 읽기 쉽게 한다. 창의 기본 조작과 단축키는 각 운영체제의 관습을 따른다. 설치 안내, 경로, 좌표 같은 세부 정보는 필요한 보조 화면에서 확인할 수 있게 한다.

| 사용자 행동 | 앱 동작 |
| --- | --- |
| 이미지 파일 드롭·파일 열기 | 이미지를 창에 맞춰 표시하고 이전 작업은 자동 보관 |
| 이미지 붙여넣기 | 이미지를 파일로 자동 보관하고 표시 |
| 이미지 클릭 | 점과 작은 입력창 생성, 즉시 타이핑 가능 |
| 이미지에서 드래그 | 사각형 영역과 입력창 생성 |
| 입력 후 다음 위치 클릭 | 작성한 지시를 보관하고 다음 지시 작성 |
| Enter | 현재 지시 확정. Shift+Enter는 줄바꿈 |
| 지시 복사 또는 Ctrl+Enter / ⌘Enter | 작성 중인 내용까지 확정하고 전체 지시 복사 |
| 번호 클릭 | 해당 지시 수정 |
| 점·영역 이동 또는 크기 조절 | 원본 픽셀 기준 대상 위치 갱신 |
| 대상 추가 | 같은 지시에 점이나 영역 추가. Shift+클릭·드래그도 지원 |
| 휠·트랙패드 확대, Space+드래그 | 이미지 확대와 이동 |
| 화면에 맞춤 | 이미지 전체를 보기 좋은 크기로 복귀 |
| Esc | 현재 조작 취소·입력 닫기. 빈 새 지시는 제거 |

한글 조합 중의 Enter는 조합 완료에 사용한다. 조합 중 확정·복사 명령은 입력 완료와 충돌하지 않도록 처리한다. 입력창에서는 텍스트 복사·붙여넣기·실행 취소가 일반 편집기처럼 동작한다. 텍스트 입력과 이미지 붙여넣기의 포커스 규칙을 두 운영체제에서 검증한다.

여러 대상을 하나의 지시로 연결할 수 있다. “이 두 버튼의 색을 같게”, “이 로고는 유지” 같은 내용은 자연어로 입력한다. 수정·유지 종류를 고르는 추가 단계를 요구하지 않는다. 앱이 점 지정만으로 사물의 정확한 윤곽을 추정하지 않으며, 범위를 명확히 할 때 사용자가 사각형을 사용한다.

**복사 결과에는 지시를 이해하는 데 필요한 정보가 완결되어야 한다.**

```text
다음 참고 이미지를 열고 지시를 반영해 주세요.

이미지: C:\work\.image-notes\<문서 ID>\reference.png
크기: 1920×1080 px
좌표: 좌상단 원점 (0, 0), x는 오른쪽, y는 아래쪽
영역: (x, y, 너비, 높이)

1. 영역 (1240, 80, 160, 48)
   버튼 배경을 파란색으로 변경.

2. 지점 (320, 460), (520, 460)
   두 아이콘의 크기를 동일하게 맞추기.

전체 지시: 문구와 나머지 배치는 유지.
```

macOS에서는 해당 컴퓨터의 실제 경로를 사용한다. 표시된 좌표와 크기는 항상 복사된 경로의 참고 이미지 기준이다. 전체 지시는 사용자가 입력한 경우에만 포함하며, 앱이 사용자의 의도를 임의로 덧붙이지 않는다. 빈 지시는 복사 결과에서 제외한다.

확대율, Retina, Windows 화면 배율과 관계없이 실제 이미지 픽셀 좌표를 유지한다. 사진의 회전 정보는 화면과 저장된 참고 이미지에 동일하게 반영한다. 점은 `(x, y)`, 영역은 `(x, y, width, height)`로 통일하고 이미지 경계를 벗어나지 않게 한다.

참고 이미지 파일과 주석 저장이 성공한 뒤 클립보드를 갱신한다. 성공하면 “지시 3개 복사됨”처럼 짧게 알린다. 복사 실패 시 작성 내용은 유지하고 재시도할 수 있게 한다. 지시문을 TXT로 저장하는 기능도 보조 메뉴에서 제공한다.

**작업은 자동 저장하며, 코드와 사용자 데이터를 별도로 보관한다.**

파일로 연 이미지와 붙여넣은 이미지 모두 주석을 작성하는 시점의 고정 참고 사본을 생성한다. 원본 파일 경로가 있으면 출처로 기록한다. 참고 사본은 원본 파일의 후속 변경과 분리해 해당 지시의 좌표 기준을 유지한다.

AI가 작업 폴더를 지정해 열면 그 폴더의 `.image-notes/<문서 ID>/`에 참고 이미지와 주석을 보관한다. 단독 실행에서는 사용자 데이터 폴더를 기본으로 사용하고 보관할 작업 폴더를 변경할 수 있게 한다. 복사된 경로를 AI가 읽을 수 있어야 한다.

주석 JSON에는 형식 버전, 문서 ID, 참고 이미지 경로·크기, 원본 출처, 각 지시의 고유 ID·텍스트·대상 목록, 전체 지시를 저장한다. 점과 사각형을 한 지시 안에 함께 담을 수 있는 구조로 만든다.

내용을 바꾸면 짧은 지연 후 자동 저장하고, 복사·정상 종료 시에는 남은 저장을 완료한다. 저장 파일은 부분 기록으로 손상되지 않게 교체한다. 작성 중인 텍스트도 복구하며, 최근 작업을 다시 열 수 있게 한다. 이미지 전환과 앱 업데이트 후에도 기존 작업을 유지한다.

**코드 구조와 실행 명령은 AI가 작은 변경을 쉽게 수행할 수 있게 만든다.**

| 구성 | 책임 |
| --- | --- |
| `src/main/` | 창, 파일, 이미지 보관, 클립보드, 실행 인자 |
| `src/preload/` | 화면에 필요한 데스크톱 기능의 제한된 인터페이스 |
| `src/renderer/` | 이미지·SVG 표시, 코멘트 입력, 단축키, 확대·이동 |
| `src/core/` | 문서 모델, 좌표 변환, 지시문 생성, 실행 취소 로직 |
| `scripts/` | 설치, 실행, 환경 확인, 사용자 수정 보존을 포함한 관리 절차 |
| `docs/` | 기획, 구조, 설치, 수정 후 확인 방법 |

Electron 화면에는 필요한 데스크톱 기능만 노출한다. 로컬 화면 코드와 파일 접근 책임을 분리해 AI가 UI를 수정할 때 저장·클립보드 동작까지 불필요하게 바꾸지 않도록 한다. 앱의 이미지·주석 데이터는 소스 폴더 바깥에 둔다.

구현할 공통 명령은 다음과 같다. 설치 결과에는 해당 명령을 실행할 작업 폴더와 실제 실행 환경의 경로를 함께 제공한다.

| 명령 | 용도 |
| --- | --- |
| `npm run build` | 수정한 코드 빌드 |
| `npm start` | 빌드된 앱 실행 |
| `npm start -- --image "<경로>" --workspace "<작업 폴더>"` | AI가 작업 이미지를 바로 열기 |
| `npm run check` | 타입과 정적 검사 |
| `npm test` | 좌표·문서·복사 결과 등 핵심 검증 |
| `npm run doctor -- --json` | 실행 환경, 버전, 경로, 데이터 저장 가능 여부 확인 |

README의 첫 부분에는 설치 지침과 완료 안내를 둔다. `AGENTS.md`에는 구조, 명령, 수정 규칙을 담고 `CLAUDE.md`에서는 같은 공통 안내를 참조한다. URL만 전달한 상황에서도 README를 통해 설치 문서를 찾을 수 있게 한다. 프로젝트 지침 파일은 각 도구의 공식 지원 방식을 따른다. [Codex 프로젝트 지침](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [Claude Code 프로젝트 지침](https://code.claude.com/docs/en/memory)

수정 규칙에는 좌표 기준 유지, 데이터 형식의 호환성, 텍스트 편집 단축키 보존, 변경에 적합한 확인 후 재실행을 명시한다. 수정 가능하다는 안내는 사용자 요청에 따라 이 앱을 변경할 수 있다는 뜻이다.

**업데이트는 개인이 바꾼 코드를 보존하는 방식으로 제공한다.**

설치한 원본 버전과 커밋 또는 소스 압축본의 기준 정보를 기록한다. 사용자가 업데이트를 요청하면 AI가 로컬 변경을 확인하고 복구 가능한 사본을 만든 뒤 새 버전의 변경을 반영한다. 병합이 해결되지 않으면 기존 실행 버전을 유지하고 충돌 내용을 설명한다. 자동으로 새 소스를 덮어쓰는 갱신 방식은 사용하지 않는다.

사용자는 앱의 동작, 배치, 단축키, 프롬프트 형식을 AI에게 요청해 수정할 수 있다. 변경 후에는 필요한 검사와 빌드를 수행하고 실제로 창이 열리는지 확인한다. 이미지·코멘트 형식이 바뀔 때는 기존 데이터의 호환성을 처리한다.

**첫 버전은 편집 흐름과 소스 설치 경험을 함께 완성한다.**

| 첫 버전에 포함 | 이후 실제 필요를 확인할 항목 |
| --- | --- |
| Windows·macOS 소스 설치, 실행 바로가기, 상태 확인 | 별도 설치 패키지 배포 |
| 설치한 AI 세션에 사용·수정 안내 | 특정 AI 제품의 별도 연동 API |
| PNG·JPEG·WebP 정지 이미지 열기와 클립보드 이미지 붙여넣기 | 추가 이미지 형식과 애니메이션 |
| 점·사각형, 여러 대상에 공통 지시 | 자동 사물 분리, OCR, 정밀 윤곽 선택 |
| 위치별 지시와 전체 지시 | 여러 이미지를 묶은 지시 |
| 지시 복사, TXT 저장, 앱 수정 안내 복사 | 주석 합성 이미지 내보내기 |
| 자동 저장·최근 작업 복구·실행 취소 | AI 결과 비교 화면 |

**개발은 설치부터 실제 AI 전달까지 이어지는 순서로 진행한다.**

| 단계 | 결과물 | 통과 기준 |
| --- | --- | --- |
| 1. 설치와 실행 | 소스 설치 스크립트, 독립 창, 상태 확인, 설치 완료 응답 | 개발 도구가 없는 Windows·Mac에서 설치되고 현재 AI 대화에 소스 수정 가능 안내가 나타남 |
| 2. 최소 사용 흐름 | 이미지 열기, 점 지정, 즉시 입력, 지시 복사, 참고 파일 보관 | 로컬 AI가 복사된 경로를 열고 지정한 위치를 이해 |
| 3. 정확한 편집 | 사각형, 대상 추가, 위치 수정, 확대·이동, 전체 지시 | 양쪽 OS의 화면 배율과 한글 입력에서 지시·좌표가 일치 |
| 4. 반복 사용과 수정 | 자동 복원, 실행 취소, TXT 저장, 앱 수정 안내 복사, 업데이트 절차 | 앱 재실행·사용자 코드 수정·업데이트 후에도 작업과 개인 수정 유지 |
| 5. 사용성 마감 | 시각 디자인, 시작·이미지 표시 성능, 실패 복구 안내 | 대표 사용 시나리오와 지원 환경에서 최종 검증 통과 |

완료 검증은 실제 사용자 흐름을 기준으로 한다.

- 깨끗한 Windows·macOS 환경에서 저장소 URL로 설치하고 Claude Code·Codex 각각의 완료 응답에 소스 경로와 수정 가능 안내가 포함된다.
- 설치 스크립트 재실행 시 기존 소스 변경과 이미지·코멘트가 유지된다.
- 일반 스크린샷에 짧은 지시 세 개를 달고 30초 안에 복사하는 것을 사용성 목표로 검증한다.
- 확대·이동·창 크기 변경·Windows 배율·Retina에서 같은 대상의 좌표가 일치한다.
- 한글 조합 Enter, 텍스트 붙여넣기, 텍스트 실행 취소와 앱 단축키가 충돌하지 않는다.
- 공백·한글이 있는 경로, 투명 이미지, 회전 정보가 있는 사진, 큰 이미지에서 참고 파일과 화면의 기준이 일치한다.
- 앱을 닫고 다시 열면 작성 중인 지시를 복구한다. 저장·클립보드 실패를 성공으로 표시하지 않는다.
- AI가 실제 작업 폴더의 참고 이미지를 열어 지시를 읽을 수 있다.
- “코멘트 글자를 크게” 같은 요청으로 AI가 설치된 소스를 수정·확인·재실행할 수 있다.
- 새 AI 세션에서 앱 수정 안내를 붙여넣으면 소스와 실행 방법을 찾을 수 있다.
- 업데이트 과정에서 개인 변경을 보존하고 실패 시 이전 실행 상태로 복구할 수 있다.
