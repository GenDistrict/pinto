브랜드 3안

index.html을 열면 세 안을 비교하고 SVG/PNG를 다운로드할 수 있습니다.

각 폴더: logo.svg 기본 로고 / logo-mono.svg 단색 / logo-reversed.svg 어두운 배경용 / mark.svg 심벌 / og.png 1200×630 / og.svg 편집 원본 / tokens.json 컬러와 규칙

로고·OG의 글자는 벡터 패스이며 별도 폰트 설치 없이 표시됩니다. 레이아웃과 컬러는 SVG에서 수정할 수 있습니다. 문구 변경은 저장소의 scripts/create_brand_concepts.py를 편집해 재생성할 수 있습니다(생성 스크립트는 Windows 폰트와 Edge를 사용).
브랜드명은 디자인 검토를 위한 가칭입니다.
